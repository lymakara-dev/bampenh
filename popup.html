Autofill

v2.2 

    


    
    

      

        Reads the current page, analyzes every input, and proposes a sample
        value for each. Review or edit them, then apply.
      

      

      


      


      

        
        
      

    


    
    

      

        Your data lives only in this browser. Keys are matched to form fields by
        label, name, and placeholder — so email fills an
        "E-mail address" field. Edit as JSON.
      

      
      

        
        
      

      


      

        Advanced: pin a value to an exact field
        

          For stubborn fields, add a "__selectors__" object mapping
          a CSS selector to a value. These run first and always win.
        

        
{
  "email": "me@example.com",
  "__selectors__": {
    "#national_id": "012345678",
    "select[name='province']": "Phnom Penh"
  }
}
